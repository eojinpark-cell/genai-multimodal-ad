## 요약

- **브랜드:** 하다 보면 끝남
- **타겟:** 계약 업무를 처음 맡거나 어려워하는 재단 직원
- **핵심 메시지:** 근거대로 한 걸음씩, 계약은 충분히 할 수 있다.
- **구조:** 문제(쌓이는 질문, 서류 미로) → 전환(법령과 선례라는 길) → 해결(단계별 조문, 질문에 대한 답) → 브랜드
- **사용 도구:** 이미지 ChatGPT / 비디오 Kling 4.0, ChatGPT / 음성 ElevenLabs / 편집 Claude(ffmpeg)
